# 달빛 배송작전 (Moonlight Delivery) — 1주차 게임 기획서

> C++ 기말 게임제작 과제 / glc2d / Git Tag `f1`

## 1. 게임 개요

| 구분 | 내용 |
|---|---|
| 게임명 | 달빛 배송작전 (Moonlight Delivery) |
| 장르 | 2D 탑다운 수집·회피 아케이드 |
| 개발 도구 | Visual Studio 2022, C++, glc2d, Git, GitHub |
| 실행 환경 | Windows PC |
| 목표 플레이 시간 | 약 3~5분 |
| 플레이 인원 | 1명 |

### 기획 의도
밤하늘 배송 로봇이 정해진 시간 안에 물품을 회수하면서 위험 구역을 피하는 게임이다. 방향키 이동이라는 단순한 조작을 사용하지만, 수집과 회피를 동시에 신경 써야 하도록 구성한다. 처음부터 복잡한 시스템을 많이 만들기보다는 하나의 핵심 플레이를 완성하고, 단계적으로 난이도와 연출을 확장하는 것을 목표로 한다.

## 2. 목표와 게임 규칙

- 목표: 제한 시간 안에 필요한 택배를 모아 배송 목표 점수를 달성한다.
- 플레이어는 화면 아래쪽에서 시작해 WASD 또는 방향키로 이동한다.
- 화면 위에서 택배와 위험 물체가 내려온다. 택배를 획득하면 점수가 올라간다.
- 위험 물체와 충돌하면 체력이 1 감소하고, 일정 시간 연속 피격을 막는다.
- 제한 시간 종료 전 목표 점수를 채우면 스테이지를 완료한다.
- 체력이 0이거나 시간이 끝났을 때 목표에 도달하지 못하면 게임 오버다.
- 총 3개 스테이지를 통과하면 최종 클리어 화면을 보여 준다.

## 3. 조작 방법

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 상하좌우 이동 |
| Enter | 시작 / 결과 화면에서 재시작 |
| Esc | 타이틀로 이동 또는 종료 |

대시는 필수 범위에서 제외해 구현 난이도를 조절한다.

## 4. 게임 진행 흐름

1. 타이틀 화면에서 시작 버튼을 누른다.
2. 스테이지가 시작되고 택배와 위험 물체가 위에서 생성되어 내려온다.
3. 플레이어는 택배를 수집하고 장애물은 피한다.
4. 목표 점수를 획득하면 다음 스테이지로 넘어간다.
5. 3스테이지 종료 후 클리어 화면, 실패 시 게임 오버 화면을 표시한다.
6. 결과 화면에서 재시작 또는 종료를 선택할 수 있다.

## 5. 주요 게임 객체

| 객체 | 역할 | 예정 동적 표현 |
|---|---|---|
| 배송 로봇 | 플레이어 이동 및 충돌 판정 | 방향에 따른 이동·보행 프레임 |
| 택배 상자 | 수집하면 점수 획득 | 낙하·수집 시 소멸 이펙트 |
| 위험 물체 | 충돌 시 체력 감소 | 낙하·회전·피격 깜빡임 |
| 배경 | 플레이 공간과 레인 표시 | 느린 별빛 스크롤 |
| HUD | 체력·점수·남은 시간 표시 | 값 갱신, 피격 알림 |
| 화면 관리자 | 타이틀·플레이·결과 전환 | 전환 및 화면 상태 관리 |

## 6. 스테이지 구성

| 스테이지 | 목표 점수(예정) | 난이도 변화 |
|---|---:|---|
| 1. 배송 연습 | 5점 | 느린 낙하, 위험 물체 적음 |
| 2. 혼잡 구역 | 8점 | 낙하 속도 증가, 장애물 생성 빈도 증가 |
| 3. 폭풍 구역 | 10점 | 빠른 낙하, 위험 물체 종류 또는 이동 패턴 추가 |

각 스테이지의 시간은 60초를 기본으로 두고 실제 테스트 후 조절한다. 숫자는 기획안이며 플레이테스트 결과에 따라 수정할 수 있다.

## 7. 구현 범위

### 필수 구현
- 타이틀 / 플레이 / 게임오버 / 클리어 화면
- 키보드 이동과 화면 경계 제한
- 택배·위험 물체의 시간 기반 이동과 반복 생성
- 충돌 판정, 점수, 체력, 제한 시간
- 스테이지별 속도 또는 생성 빈도 변화
- 최소한의 이동·피격·수집 애니메이션

### 시간이 남으면 추가할 내용
- 회복 아이템 또는 보너스 점수 아이템
- 배경 스크롤과 간단한 파티클 이펙트
- 사운드 및 최고 점수 저장

## 8. 구현 방법 및 개발 계획

| 구분 | 구현 계획 |
|---|---|
| 입력 처리 | `g2_GetKeyboard()`를 사용하여 입력 확인 |
| 화면 표현 | glc2d 텍스처 로딩과 `g2_Draw2D()`로 그리기 |
| 업데이트 | `g2_SetFrameMove()`의 갱신 함수를 이용 |
| 화면 렌더링 | `g2_SetRender()` 콜백을 이용 |
| 충돌 | 객체를 사각형 영역으로 정의해 AABB 충돌 계산 |
| 화면 상태 | enum으로 Title / Playing / GameOver / Clear 상태 구분 |
| 객체 관리 | Player, FallingObject 등의 기본 클래스 분리 예정 |

### 주차별 목표

| 주차 | 목표 | Git 태그 |
|---|---|---|
| 1주차 | 실행 환경, 움직이는 오브젝트 시제품, 기획서 | `f1` |
| 2주차 | 이미지·사운드 정리, 클래스 분리, 기본 화면 구현 | `f2` |
| 3주차 | 충돌, 수집, 체력, 시간, 점수와 실제 플레이 | `f3` |
| 4주차 | 난이도 확장, 애니메이션 및 연출 보완 | `f4` |
| 최종 | 버그 수정과 처음부터 끝까지 플레이 완성 | `fin` |

## 9. 1주차 구현 현황

현재 1주차 소스에는 기본 게임 창 생성, 키보드 이동, 플레이어 화면 경계 제한, 낙하 물체 2종의 반복 이동 및 이미지 출력이 포함되어 있다. **충돌, 수집, 점수, 게임 종료, 3개 스테이지는 아직 구현하지 않은 예정 기능이다.**

기획서와 실제 구현을 구별하기 위해 현재 완료된 부분을 명시한다.

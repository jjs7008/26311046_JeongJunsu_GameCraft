# 4주차 개발 보고서 - 달빛 배송작전 (Moonlight Delivery)

## 개발 목표
기존 3주차의 이동, 택배 수집, 충돌, 체력 및 게임오버 구조를 유지하고 스테이지/난이도/패턴의 확장과 시간 기반 시각 효과를 구현한다.

## 스테이지 구성

| 스테이지 | 누적 점수 목표 | 장애물 | 기본 택배 속도 | 기본 장애물 속도 | 추가 규칙 |
|---|---:|---|---:|---:|---|
| 1 | 50점 | 1개 | 1.30 px/tick | 1.55 px/tick | 기본 조작 익히기 |
| 2 | 110점 | 2개 | 1.58 px/tick | 2.01 px/tick | 추가 장애물 등장 |
| 3 | 180점 | 2개 | 1.86 px/tick | 2.47 px/tick | 장애물 좌우 주기 운동 |

* 모두 60Hz 고정 업데이트 기준이며, 점수는 스테이지를 진행해도 초기화하지 않는다.
* 3스테이지의 목표 점수를 달성하면 게임 클리어 화면으로 이동한다.

## 신규 구현
- `Game::StartStage`로 스테이지 시작/전환 및 단계별 목표점수 관리
- 두 번째 장애물 `hazard2`를 2스테이지부터 활성화
- 3스테이지 장애물에 `sin` 함수를 이용한 좌우 흔들림 패턴 적용
- 스테이지별 배경 이미지 분리 (`background_stage2.png`, `background_stage3.png`)
- 화면 상단에 스테이지, 누적 점수, 남은 체력, 경과 시간 표시
- 시작 시 2초 안내, 아이템 획득 시 `+10`, 피격 시 `HIT!` 표시
- 기존 플레이어 피격 깜빡임 애니메이션 유지
- 60Hz 고정 업데이트를 유지해 FPS에 따른 속도 변화 방지

## 조작 및 확인 순서
1. Visual Studio에서 `MoonlightDelivery.sln`을 열고 NuGet 패키지를 복원한다.
2. x64 Debug로 빌드 후 실행한다.
3. Enter로 시작하고 WASD/방향키로 이동한다.
4. 택배를 5개 모으면 2스테이지로 바뀌는지 확인한다.
5. 총 11개 모으면 3스테이지에서 좌우로 움직이는 장애물이 나오는지 확인한다.
6. 총 18개 모으면 클리어 화면이 나오는지 확인한다.
7. 장애물에 3번 피격되면 게임오버, Enter로 재시작이 가능한지 확인한다.

## 4주차 평가 기준 대응
- **스테이지 및 콘텐츠 확장(10점)**: 3스테이지 목표/속도/장애물 수/장애물 패턴 차별화
- **애니메이션 및 동적 연출(5점)**: 장애물 주기 운동, 피격 깜빡임, 획득·피격 알림 및 스테이지 진입 안내

## 미완료 및 후속 보완
- 실제 Windows / Visual Studio 컴파일 및 플레이 테스트는 사용자 환경에서 필요하다.
- 장시간 플레이 밸런스 및 사운드 재생은 최종 제출 전 점검 대상이다.

# 3주차 - 핵심 게임 로직 구현

## 목표 (15점)
- 핵심 게임 로직 (10점): 이동, 아이템과 장애물의 AABB 충돌 판정, 점수, 체력, 피격 무적 시간, 상태 전환
- 기본 플레이 (5점): 시작부터 성공/실패까지 실제로 조작 가능한 게임

## 구현 사항
1. 타이틀에서 Enter로 게임 시작
2. WASD/방향키로 캐릭터 이동 (화면 경계 제한)
3. 택배와 접촉 시 점수 +10 후 택배 재생성
4. 장애물과 접촉 시 HP -1, 약 65프레임 피격 무적 및 깜빡임
5. HP가 0이 되면 Game Over, 100점을 모으면 Clear
6. Enter 재시작, Esc로 타이틀 이동
7. 낙하 오브젝트가 화면을 벗어나면 다른 레인에서 재생성

## 다음 주차 예정
스테이지별 목표 점수, 적 속도 및 등장 패턴 변경, 애니메이션 강화, 게임 연출 보완.

## 테스트 항목
- 아이템 획득 점수가 한 번만 증가하는가
- 피격 직후 일정 시간 중복 피해가 없는가
- 체력이 0일 때 Game Over로 넘어가는가
- 점수가 100에 도달하면 Clear로 넘어가는가
- Enter 재시작 때 점수와 체력이 초기화되는가

※ Windows Visual Studio 2022에서 실제 빌드 및 실행 여부는 제출 전에 직접 확인해야 합니다.

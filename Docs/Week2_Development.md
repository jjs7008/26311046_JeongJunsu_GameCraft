# 달빛 배송작전 — 2주차 개발 정리

## 1. 주차 목표 및 평가

교수님 평가 기준: **리소스 준비(5점)**, **프로젝트 기본 구조(10점)**. 1주차 프로젝트를 기반으로 진행한다.

리소스는 과제용으로 생성한 그래픽과 간단한 파형 효과음이다. 외부 저작권 음원은 사용하지 않았다. 음원 재생은 3주차 수집 및 피격 로직 구현 시 연결할 계획이다.

## 3. 클래스/구조

- `main.cpp`: glc2d 초기화, 프레임 및 렌더 콜백 등록, 종료
- `Game.h/.cpp`: 게임 화면 상태, 리소스 로드/해제, 화면 전환 및 객체 관리
- `Player.h`: 플레이어의 이동, 초기화, 화면 출력
- `FallingObject.h`: 택배/장애물 낙하 및 반복 등장
- `GameScreen` enum: Title, Playing, GameOver, Clear 구분

## 4. 현재 확인 가능한 동작 (코드상 구현)

1. 타이틀 화면에서 Enter를 누르면 플레이 화면으로 전환
2. WASD 또는 방향키로 로봇 이동, 화면 밖 이동 제한
3. 택배와 위험 물체가 아래로 움직이며 화면 아래에서 재등장
4. Esc를 누르면 타이틀로 복귀
5. Space를 누르면 **게임오버 화면 미리보기**로 전환하고 Enter로 타이틀 복귀

`Clear` 화면 이미지는 준비했지만 클리어 판정과 그 화면으로의 전환은 **아직 미구현**이다. 충돌, 점수, 수집, 체력, 타이머도 **3주차 구현 예정**이다. 실제 게임오버 판정은 아직 없다.

## 5. 실행 안내 및 남은 확인

Windows 환경의 Visual Studio 2022에서 `MoonlightDelivery/MoonlightDelivery.sln`을 열고 glc2d / DXSDK NuGet 복원 후 `Debug | x64`로 실행한다. 본 제출 패키지는 Windows 빌드 및 실기 테스트를 하지 못했으므로 사용자가 반드시 실행 화면을 확인해야 한다.
